📊 Project Overview

The UPI Transaction Dashboard is an interactive data analytics project designed to analyze UPI (Unified Payments Interface) transactions and uncover meaningful business insights.

This dashboard provides a comprehensive overview of transaction performance, payment methods, transaction statuses, cashback distribution, suspected fraud, and transaction trends across different states, banks, and time periods.

The primary objective is to transform raw transaction data into meaningful visual insights that support better decision-making and help understand digital payment behavior.

Analyze overall UPI transaction performance.

Monitor total transaction amounts and cashback distribution.

Identify popular UPI payment applications.

Analyze successful, failed, pending, and refunded transactions.

Identify suspected fraudulent transactions.

Compare transaction amounts across Indian states and banks.

Understand hourly and daily transaction patterns.

Build an interactive dashboard for better data-driven decision-making.

🔍 Interactive Filters

The dashboard includes interactive filters to explore transaction data from different perspectives:

Gender: Female, Male, Other.

City: Filter transactions by city.

Age Group: Analyze different customer age groups.

Merchant Category: Filter by merchant and transaction categories.

These filters allow users to explore specific segments and gain deeper insights into transaction behavior.

💡 Key Insights

The dashboard helps identify:

PhonePe has the highest share among the displayed UPI applications.

The overall transaction success rate is approximately 91%.

Failed and pending transactions provide opportunities to investigate payment issues.

State-wise and bank-wise comparisons reveal differences in transaction values.

Hourly and daily trends help identify periods of higher transaction activity.

Suspected fraud records can help identify transactions requiring further investigation.
